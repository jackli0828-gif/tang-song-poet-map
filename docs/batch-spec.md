## 2. 数据结构（必须严格遵守）

```ts
interface Work {
  id: string;            // '<作者拼音>-w1'、'-w2'…
  title: string;
  genre: string;         // 见第 4 节体裁表
  year: number;          // 创作年份（公元），必须落在作者生卒年区间内
  yearLabel?: string;    // 年号纪年，如 '开元十五年'、'熙宁九年'
  placeId: string;       // 必须等于所在节点的 id
  excerpt: string;       // 名句或节选（1-4 句）
  fullText?: string;     // 短篇给全文，长篇给节选
  background: string;    // 一句话创作背景；系年不确定时在此说明「系年存疑」
  tags?: string[];       // 题材：山水/边塞/送别/思乡/闺怨/咏史/咏物/羁旅/隐逸/忧国/爱情/节令…
}

interface LifeNode {
  id: string;            // '<作者拼音>-n1'、'-n2'…
  year: number;          // 公元年份
  yearRange?: [number, number];  // 在某地停留的年份区间（可选）
  era?: string;          // 年号，如 '天宝三载'
  place: string;         // 古地名，如 '长安'、'汴京'、'黄州'
  modernPlace: string;   // 今地，如 '陕西西安'、'河南开封'、'湖北黄冈'
  lng: number;           // 现代对应地经度（必须中国范围内：73~136）
  lat: number;           // 现代对应地纬度（必须中国范围内：18~54）
  age?: number;          // 该年年龄（= year - birthYear）
  eventType: 'birth' | 'travel' | 'office' | 'exile' | 'seclude' | 'sociable' | 'death';
  event: string;         // 一句话人生事件（30-80 字，要有信息量，不要空话）
  works: Work[];         // 该地该时创作的作品（可以是空数组）
  note?: string;         // 生卒/系年有异说时说明
}

interface Poet {
  id: string;            // 拼音连写，如 'cen shen' → 'censhen'；必须与节点 id 前缀一致
  name: string;
  courtesy?: string;     // 字
  pseudonym?: string;    // 号
  dynasty: '唐' | '宋';
  birthYear: number;
  deathYear: number;
  birthplace: string;    // '襄州襄阳（今湖北襄阳）' 这种古今双写格式
  brief: string;         // 2-3 句小传（60-120 字）
  avatarColor: string;   // 从下面的色板里挑，同一批次尽量不重复
  nodes: LifeNode[];     // 按年份升序
}
```

## 5. 每位作者的编写要求

- **节点数**：4~7 个。第一位作者（批次里的大家，如岑参、高适、王昌龄、韦应物、元稹、刘禹锡、温庭筠；范仲淹、秦观、周邦彦、贺铸、张孝祥、吴文英、周密、蒋捷、张炎、王沂孙）给 6~7 个；小家给 4~5 个。
- **第一个节点必须是出生地**（eventType: 'birth'），**最后一个节点必须是卒地**（eventType: 'death'）。
- **作品优先选其入选《唐诗三百首》/《宋词三百首》的篇目**（这是本项目的核心口径）。每篇必须挂到一个具体节点上，不要凭空造节点。
- 每篇作品的 `year` 必须在其所属节点的 `year`（或 yearRange）附近，且落在作者生卒年之间。
- **系年不可考时**：把作品挂到最可能的地点节点，并在 `background` 里写「系年存疑」，不要编造精确年份。
- 节点按 `year` 升序排列。

## 7. 硬性约束（写完后必须自查）

1. `id` 全局唯一：`<拼音>-n*`、`-w*` 不得在同一文件内重复，拼音不得与已有 18 家冲突（libai / dufu / wangwei / baijuyi / hanyu / liuzongyuan / dumu / lishangyin / menghaoran / weizhuang / sushi / xinqiji / liqingzhao / luyou / ouyangxiu / liuyong / yanshu / jiangkui）。
2. 每个 `Work.placeId` 必须等于其所在 `LifeNode.id`。
3. 所有 `year`（节点与作品）落在 `[birthYear, deathYear]` 内。
4. `nodes` 按 `year` 严格升序；首节点 eventType='birth'，末节点 eventType='death'。
5. `lng` ∈ [73, 136]，`lat` ∈ [18, 54]。
6. `age` = `year - birthYear`（虚岁可 +1，但同一作者内要一致）。
7. **不许杜撰**：生平大事、任职地名、作品系年都要有依据；不确定处用 `note` 或 `background` 标注「系年存疑」「一说」。宁可少写一个节点，也不要编造。
8. 文案用简体中文，风格与范例一致（文白相间的说明文字，不用口语）。
