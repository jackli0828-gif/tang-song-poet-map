## 四、输出格式

写入 `scripts/_xchunks/result_<批次号>.json`：

```json
[
  {
    "id": "libai",
    "name": "李白",
    "status": "CORRECTED",
    "confidence": "HIGH",
    "sources": ["《旧唐书·李白传》", "百度百科", "《李白年谱》"],
    "corrections": [
      {
        "field": "birthYear",
        "from": 701,
        "to": 701,
        "note": "三源一致，无需改动"
      },
      {
        "field": "nodes.libai-5.year",
        "from": 744,
        "to": 744,
        "note": "天宝三载，赐金放还，与杜甫会于洛阳，确认无误"
      }
    ]
  }
]
```

字段规则：
- `status`：`OK`（无需改动）或 `CORRECTED`（有订正）
- `confidence`：`HIGH`（≥2 独立权威源）/ `MEDIUM`（单一权威源）/ `LOW`（存疑，维持原值）
- `field` 路径：作者级直接写字段名；节点级写 `nodes.<nodeId>.<field>`；作品级写 `works.<workId>.<field>`
- `corrections`：无改动时为空数组 `[]`
- **存疑时**：`status: "OK"` + `confidence: "LOW"` + 在 `note` 里写明争议点（如「生年有 701/699 两说，维持原值 701」）

## 七、常见易错点（重点核对）

### 生卒年
- 正史多记「卒于某年，年若干」，需回推生年，注意**虚岁**
- 生卒年有异说时（如王维 699/701/694），**维持项目原值**并标注异说

### 年号换算
- 唐：武则天时期年号更迭频繁；**天宝三载起改「年」为「载」**（742–756 称「载」）
- 唐：开元 29 年（741）→ 天宝元年（742）
- 宋：年号多且短（如宋徽宗有建中靖国、崇宁、大观、政和、重和、宣和），**必须逐一核对**
- 改元当年：同一公元年可能对应两个年号（如 712 年 = 太极/延和/先天）

### 地名
- 同名异地：如「金陵」（今南京）、「京口」（今镇江）、「广陵」（今扬州）
- 唐代贬所：岭南（今两广）、崖州（今海南）、潮州（今广东潮州）
- 宋代：汴京/东京（今开封）、临安（今杭州）、建康（今南京）

### 事迹
- 贬谪年份：注意「贬」与「量移」「召回」的时间差
- 交游：两人同地需年份相近（≤3 年）才算合理
- 作品系年：长篇（如《长恨歌》）系年常有争议，存疑标 LOW
